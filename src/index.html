Pangram for Word

A Microsoft Word add-in that scores the open document with Pangram AI detection: one number, a gauge, and a link to the full analysis. You bring your own Pangram API key.

Download the add-in manifest

Install

  1. Mac: put the manifest in ~/Library/Containers/com.microsoft.Word/Data/Documents/wef/ (create the wef folder if needed; Finder works if Terminal is blocked).
    Windows: use a shared-folder catalog.
  2. Quit and reopen Word, then click Pangram on the Home tab.
  3. Open the pane's settings (gear icon), paste your Pangram API key, and hit Analyze document.

Privacy

Your API key is kept in the add-in pane's local storage on your device. When you run an analysis, the key and the document's text pass through this server to Pangram's API, because Pangram's API cannot be called directly from the pane. Neither is stored or logged here. If you would rather not rely on this host, the project is open source and deploys to your own Vercel account or runs on localhost.
