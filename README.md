# Pangram for Word

A Microsoft Word task-pane add-in that scores the open document with
[Pangram](https://www.pangram.com) AI detection. Click **Pangram** on the Home tab,
hit **Analyze document**, and the pane shows the AI percentage on a semicircle dial,
the AI / AI-assisted / human split, the Pangram model version, and a **Full analysis**
button that opens the result in the Pangram dashboard.

No build step: plain HTML/CSS/JS served by a tiny Node HTTPS server that also proxies
to Pangram (the API sends no CORS headers, and this keeps your key out of the webview).

## One-time setup (local)

```sh
npm install
npm run certs        # trusts a localhost dev cert (Word requires HTTPS); keychain prompt
cp .env.example .env # then set PANGRAM_API_KEY (and optionally PANGRAM_MODEL)
npm run sideload     # renders manifest.xml for ADDIN_BASE_URL and copies it into Word's add-in folder (Mac)
```

If macOS refuses to write into Word's folder from the terminal, run `npm run manifest`
and copy `manifest.xml` into
`~/Library/Containers/com.microsoft.Word/Data/Documents/wef/` with Finder instead.

Quit and reopen Word after sideloading. If the Home-tab button doesn't appear, use
**Insert > Add-ins > My Add-ins > Pangram**.

## Every session

```sh
npm start            # https://localhost:3939 — keep this running while you use the pane
```

Then open the pane from the Home tab and click **Analyze document** (or the refresh
icon in the pane header) whenever you want a fresh score. The last result is remembered
per document so reopening the pane shows the previous score with its timestamp.

You can also paste an API key in the pane's settings (gear icon); it's stored in the
pane's local storage and overrides the `.env` key.

## Hosting on your own site

The pane is static files plus two proxy endpoints, so it can live on any HTTPS host,
and then Word needs nothing running on your machine. This repo is an npm package
(`pangram-for-word`) that exports the proxy handlers and a publish script, so a site
can depend on it and build the pane at deploy time. `site/` has the Next.js wiring:

```json
"scripts":      { "prebuild": "pangram-for-word-publish . https://example.com/pangram" },
"dependencies": { "pangram-for-word": "github:GaneshPimpale/pangram_for_word" }
```

The prebuild copies `src/` and `assets/` into `public/pangram/` and writes a matching
`manifest.xml` there (gitignore that folder; it's generated). Two one-line route
handlers expose `handleStatus` and `handleAnalyze` at `/pangram/api/*`. To ship a new
add-in version to the site: `npm update pangram-for-word`, commit the lockfile, deploy.

Users download `https://example.com/pangram/manifest.xml` and sideload it (Mac: the
`wef` folder above; Windows: a shared-folder catalog).

Do **not** set `PANGRAM_API_KEY` on a public host: the proxy would let anyone spend
your credits. Leave it unset and the pane asks each user for their own key, which is
kept in the pane's local storage and sent straight through to Pangram.

## Layout

- `lib/pangram.mjs` — the proxy (creates a task with `POST /task`, polls `GET /task/{id}`),
  exposed as web-standard `handleStatus` / `handleAnalyze` handlers.
- `server.js` — local HTTPS static server that runs those handlers at `/api/*`.
- `src/taskpane.html|css|js` — the pane. Open
  `https://localhost:3939/taskpane.html?mock=1&run=1` in a browser to preview it
  outside Word with canned data (`&ai=0.6&assisted=0.1&theme=dark` to vary it).
- `manifest.template.xml` — Office add-in manifest; `npm run manifest` renders `manifest.xml`
  from it using `ADDIN_BASE_URL`.
- `site/` — Next.js route handlers + landing page for hosting the pane on a website.
- `scripts/publish-site.mjs` — the `pangram-for-word-publish` bin used by a site's prebuild.
- `assets/` — icons, generated by `npm run icons`.

## Notes

- The dial shows the non-human share (`fraction_ai + fraction_ai_assisted`); the bar
  underneath shows the split. Model version comes from the response's `version` field.
- Pangram bills per request. A `402 Insufficient credits` error means the account
  behind the key has no API credits.
- Port is 3939; change it in `.env` **and** `manifest.xml` together.
